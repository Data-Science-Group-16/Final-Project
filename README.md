# Final-Project
Age and Fantasy Football Performance (NFL, 2010-2026)

Group Members: Connor Elliott, Harrison Barnes, Stephen Heagarty, Levi Pigues, Monica Mawi

## Research Question
At what age does a player's average fantasy football points per game (PPG) peak and decline for running backs (RB), wide receivers (WR), tight ends (TE), and quarterbacks (QB) from 2010 to 2026?

### Overview
Most research on aging in sports focuses on injuries or career length. Fewer studies look at when on-field production actually peaks, and almost none use fantasy points as the outcome. This project estimates position-specific age curves for NFL skill players using fantasy PPG, and checks whether those curves have shifted over time.

We chose this topic because our group enjoys watching and playing sports, and because there is plenty of publicly available football data to work with.
